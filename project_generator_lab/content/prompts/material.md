Задача: содержимое одного файла из materials/.

Вход: material — path, kind, purpose, contains, not_contains; tasks — задания, которые им пользуются; introduction — введение с ситуацией проекта (материалы пишутся сразу после своего задания, поэтому введения может ещё не быть: тогда ситуация — в project и в context заданий); written_materials — уже написанные файлы проекта (путь и начало): люди, имена, роли, числа и сроки в новом файле должны быть ТЕ ЖЕ, если файл не про отдельную учебную ситуацию; attached_files — файлы методолога: если там есть данные или шаблон для этого материала, опирайся на них.

Если файл описывает другую ситуацию, чем основной сюжет (например, образец формата на постороннем примере), скажи это в первой строке файла явно: «Отдельная учебная ситуация, не связанная с командой из эпизодов».

Правила:
- Если material.target_words больше нуля, это согласованный объём корпуса: он важнее ориентиров по часам. Код подготовит текст частями. Реалистичный корпус требует разнообразных законченных диалогов, тематик, участников и распределения частот; объём не заменяет качества. Данные синтетические.
- Материал — сырьё для работы участника: данные, заготовка, образец формата, справка. Не решение.
- not_contains соблюдай строго: нет итогов, правильных ответов, эталонных выводов, заполненной за участника части, подсказок в комментариях.
- Данные вымышленные, правдоподобные и согласованы с сюжетом и заданиями: имена, числа, даты, единицы. Если задание требует найти ошибки, аномалии или противоречия — они есть в данных, но ничем не помечены.
- kind=sample показывает формат на другом, простом примере, а не на данных задания. kind=template — пустые поля или колонки с понятными подписями.
- Формат строго по расширению: CSV — строка заголовков и разделитель «,», одинаковое число колонок; JSON и YAML — валидные; .md и .txt — обычный текст; .py и .sql — заготовка без решения.
- Объём — сколько нужно заданию по его часам (tasks[].hours): на задание до 2 ч — десятки строк данных, на 4–6 ч — столько, что вручную не перебрать за несколько минут (сотни строк, несколько связанных таблиц или разделов). Без повторов и заглушек вроде TODO.

Поля: content — полный текст файла; note — одна фраза для методолога: что внутри и какие допущения.
