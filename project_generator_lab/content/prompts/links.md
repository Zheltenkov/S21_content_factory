Задача: выбрать источники для разделов теоретического блока из страниц, которые код уже открыл.

Вход: topics — разделы (number, title, text, keywords); search_answer — что ответила поисковая модель (для контекста); candidates — открывшиеся страницы: number, url, page_title, page_start (начало текста страницы).

picks — для каждого раздела 1–3 лучших кандидата: topic (номер раздела), candidate (номер кандидата), title (понятное название источника по-русски, по page_title), why (одна короткая фраза: что участник там найдёт).
Если page_start говорит, что сайт не отдал текст проверке, страница существует, но её содержимое не прочитано: суди о ней по адресу и по тому, что о ней сказано в search_answer; бери её, только если это известный источник по теме (официальная документация, учебник).
Бери страницу, только если по её заголовку и началу видно, что она по теме раздела и полезна участнику: документация, учебный материал, разбор. Не бери главные страницы сайтов без нужного материала, рекламу услуг, страницы входа, агрегаторы и страницы с решением учебного задания. Одна страница может подойти нескольким разделам.
Выбирай только из candidates по номеру; адресов не пиши. Если разделу ничего не подошло, не выбирай ничего и назови раздел в note.
