# Ограничения платформы

- В кампусах есть компьютеры на ARM (Mac). Не требовать ПО и версии, которые на ARM не работают, без пометки об этом.
- Нельзя требовать того, что невозможно сделать на компьютерах кампуса: установка системного ПО, права администратора — только если это явно подтверждено методистом.
- Инструменты и сервисы предлагать с учётом доступности из России. Если нужен VPN или Docker (например, для n8n), это отдельное условие, которое называет методист.
- Первый день бассейна: участники нулевого уровня могут не знать терминала и Git Bash. Всё, что с ними связано, вводится с примером до использования.
- Версии Python, Git и другого ПО в кластере: ожидается от методистов.
