Проверка требований и экспертный обзор

Задания, теория, материалы и P2P проверяются вместе с требованиями и контекстом программы. Итоговая рекомендация — только по 1–40. Замечания 41–56 помогают обсудить качество и не влияют на результат. Работа с проектом остаётся доступной.

Перечень выдаваемых файлов и повторная проверка

Необязательный утверждённый перечень: по одному относительному пути на строку. Файлы, которые участник создаёт сам, сюда не входят. Без перечня проверка состава останется неполной.

По умолчанию неизменные результаты используются повторно. Полная переоценка делает новые вызовы модели.

Профиль оценки экспериментальный; итог — рекомендация для методолога.

Что ограничивает проверку

    Что исправить

    Одна подтверждённая причина может затрагивать несколько критериев. Связанные оценки сохраняются для проверки требований и не складываются в повторные штрафы.

    ОР → действие → результат → P2P

    Свидетельства в обязательных заданиях

    Связи появятся после содержательной проверки. Само наличие задания не подтверждает достижение ОР.

    Итог определяется по подтверждённым замечаниям и полноте проверки 1–40. Неизвестные условия и неподтверждённые цитаты не являются выполненными требованиями. Универсальный балл качества не откалиброван. Критерии 41–56 — экспертные замечания без баллов и влияния на итог.
