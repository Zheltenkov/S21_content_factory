## Границы выпуска

Подгонка длинного переведённого текста в этот выпуск **не входит**.
Проверенная английская презентация из предыдущего шага подогнана по
измерениям PowerPoint отдельно; модуль не выполняет эту подгонку автоматически.
Надписи внутри изображений не переводятся. Выпуск подтверждает приём и
обработку больших PPTX, но не гарантирует одинаковую вёрстку для всех языков.

Локальные свидетельства: `.tmp/release/translation-pptx-20261123-01/`:
`deployed.json`, `https-verification.json`, `browser-verification.json`,
`final-verification.json`; секреты в эти свидетельства не входят.
