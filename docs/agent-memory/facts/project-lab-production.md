С 2026-09-17 модуль опубликован как карточка «Подготовка проекта» на главной странице боевого приложения. По согласованному объёму это подготовка замысла; старый генератор, обработка УП в нём и стандартный шаблон не заменялись.

2026-09-22 опубликован релиз `20260922-01` с версией правил 0.2. Пользователь поручил реализовать согласование карточки входов, реестр чтения, проверку с основаниями и решения методолога. Это разрешение на реализацию данного процесса; остальные вопросы из методологического документа и общие числовые метрики качества всё ещё требуют согласования. Обновлён только контейнер модуля, существующие снимки сохранены. Состояние `input_review` отсутствовало в 0.1: перед откатом учитывать совместимость новых запусков.

Размещение, проверки, пути к конфигурации и копиям для отката: [project_generator_lab/deploy/README.md](../../../project_generator_lab/deploy/README.md).

Текущий релиз — `20260923-02`, правила 0.3 (23 сентября). Пользователь явно потребовал демонстрационный режим на всех этапах: замечания к источникам, входам, замыслу и проверке показываются предупреждениями и не запрещают продолжение или согласование. Это демонстрационное решение, а не подтверждение спорных фактов. Политика действует и для уже сохранённых результатов. Диагностика и непрочитанные файлы остаются видимыми, их содержимое не выдумывается. Реальные ошибки выполнения и авторизация не отключаются.

Учётные данные SSH были переданы пользователем в задаче; в файлы проекта они не сохранялись. Не переносить локальные экспериментальные запуски и не разворачивать весь грязный checkout ради этого модуля.


Правила 0.3: общий смысл полей (`input_semantics.py`), сравнение требуемого и планируемого действия по каждому ОР, согласование итогового заключения со статусами, план будущих материалов. Опции таблиц/формул/диаграмм относятся к дополнительному оформлению текста и не отменяют явные ОР. Получаемые навыки не являются подтверждённой входной подготовкой. Новые правила применяются к новым версиям; старые результаты не перегенерированы.

Проверены 67 тестов, типы, линтер, UI desktop/mobile и два реальных прогона по прежним входам. Модель иногда пропускает поля JSON: адаптер делает один форматный повтор, успешный повтор учитывается в токенах/длительности и schema_repairs. Содержательная проверка остаётся модельной и допускает ложные замечания и пропуски; обязательна дальнейшая калибровка на решениях методолога, обещать полную точность нельзя. Прежние ошибочные замыслы не всегда распознаются критиком, даже с явными примерами.


По запросу пользователя в 20260923-02 временно убраны из интерфейса формы/записи решений методолога по замечаниям и вкладка «Изменения». Сами замечания остаются. Серверное сохранение истории и решений, экспорт JSON и API сохранены для будущей полноценной работы. Повторные пояснения о демонстрационном режиме скрыты, режим без блокировок остаётся. Изменение интерфейса применяется к старым результатам после обновления страницы.
