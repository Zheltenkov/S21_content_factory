Модуль перевода разбирает файлы, пришедшие от пользователя, а в переводе архива — файлы внутри
загруженного архива. За октябрь 2026 автоматический разбор нашёл в этом коде восемь уязвимостей
подряд, и все восемь оказались об одном:

| Где | В чём было дело |
|---|---|
| `xml_safety` | объявленные сущности XML разворачивались в гигабайты |
| `xml_safety` | проверка по сырым байтам обходилась кодировкой UTF-16 |
| `yaml_file` | псевдонимы YAML множили обход степенью вложенности: 5 строк → 33 333 единицы |
| `pdf` | поиск соседнего блока перебором всех блоков страницы — O(n²) |
| `html` | незакрытый тег заставлял перечитывать файл с каждой позиции — 68 с |
| `html` | приведение файла к нижнему регистру на каждый тег — 106 с |
| `zip_safety` | предел на загрузку считает сжатый размер; 25 МБ разворачиваются в сотни гигабайт |
| `zip_safety` | сто мегабайт XML — нормальный предел чтения и гигабайты памяти при разборе |

**Почему:** ограничение на результат не ограничивает работу, которую делаешь до того, как
результат появится. Потолок «не больше N переводимых кусков» считает только то, что уже нашёл; в
файле из одних незакрытых тегов кусков нет вовсе, счётчик стоит на нуле, а время уже потрачено.
Так же и с размером: предел на вход в сжатом виде ничего не говорит о памяти после распаковки, а
предел на чтение — о памяти после разбора.

**Как применять:** при работе с любым файлом из внешнего источника проверять три вещи отдельно,
потому что ни одна не следует из другой.

1. **Вход** — размер до и после распаковки, число частей, соотношение одного к другому.
2. **Проход** — стоимость самого разбора. Курсор обязан двигаться вперёд; поиск соседа не должен
   быть перебором; ссылку (псевдоним YAML, якорь, общий узел) обходить один раз, помня
   посещённое по тождеству; незакрытую конструкцию дочитывать до конца один раз, а не заново с
   каждой позиции.
3. **Результат** — число единиц и знаков.

И отдельно: **проверять и разбирать надо одинаково**. Если проверка читает байты, а разборщик
понимает кодировки, проверки нет — её обойдут сменой кодировки. Решение переносить внутрь того,
кто разбирает.

Проверку на стоимость прохода удобно писать тестом со временем: вход, который заведомо зловреден,
и потолок в несколько секунд. Такие тесты в `tests/translation/` показали 68 и 106 секунд там, где
глазами ничего видно не было.
